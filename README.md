# Calculadora en C con GTK

Calculadora completa con interfaz gráfica desarrollada en C usando GTK3.

## Características

- ✅ Modo Normal y Científico
- ✅ Operaciones básicas (+, -, ×, ÷)
- ✅ Funciones trigonométricas (sin, cos, tan)
- ✅ Modo DEG/RAD para ángulos
- ✅ Logaritmos y potencias
- ✅ Constantes matemáticas (π, e)
- ✅ Interfaz con pestañas
- ✅ Multiplataforma (Linux, Windows, macOS)
